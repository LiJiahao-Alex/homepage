Wavelet Domain Steganography for Robust Unlearnable Data

Jiahao Li, Yiqiang Chen*, Yunbing Xing, Yang Gu

Pattern Recognition · Vol. 180, Part D · 114422

Embeds class-specific signals in wavelet subbands to disrupt unauthorized learning while preserving fine image detail. The paper evaluates the protection under common data augmentations and adversarial training.

GSM: Global Semantic Memory

Jiahao Li, Yiqiang Chen*, Yunbing Xing, Yang Gu, Xiangyuan Lan

Pattern Recognition · Vol. 169 · 111950 · Online in 2025

Studies why reconstruction-based detectors can miss anomalies that share local features with normal samples. A cascade memory captures global semantics, using configurable sparsification and random forgetting.

K-Space Bispectrum Steganography for Robust Unlearnable Data

Jiahao Li, Yiqiang Chen*, Yunbing Xing, Yang Gu, Xiangyuan Lan

ACM Multimedia (ACM MM) · Dublin, Ireland

Uses Fourier bispectrum steganography to encode class-specific information in image magnitude and phase. The method aims to make training data harder to learn from while keeping perturbations visually subtle.

Contrast Memory for Unsupervised Anomaly Detection

Jiahao Li, Yiqiang Chen*, Yunbing Xing, Yang Gu, Xiangyuan Lan

IEEE ICASSP · Hyderabad, India

Introduces DiMER, a lightweight model for multivariate time series. Contrast memory learns normal patterns, while anomaly scores combine evidence from reconstruction, temporal, and latent spaces.

HYMAN: Hybrid Memory and Attention Network for Unsupervised Anomaly Detection

Jiahao Li, Yiqiang Chen*, Yunbing Xing, Yang Gu, Xiangyuan Lan

IEEE ICASSP · Hyderabad, India

Combines attention for short-term dependencies with memory for long-term patterns in multivariate time series. Its anomaly score uses both temporal and latent features.

A Survey on Unlearnable Data

Jiahao Li, Yiqiang Chen*, Yunbing Xing, Yang Gu, Xiangyuan Lan

arXiv:2503.23536

Reviews methods for making data resistant to unauthorized training, along with benchmarks, evaluation metrics, and applications. It compares the trade-offs among protection strength, visual fidelity, efficiency, and robustness.

Cascade Memory for Unsupervised Anomaly Detection

Jiahao Li, Yiqiang Chen*, Yunbing Xing, Yang Gu, Xiangyuan Lan

ECAI · Santiago de Compostela, Spain

Introduces a cascade memory architecture for learning global semantics. Sparsification and random forgetting help reduce the tendency to reconstruct anomalous samples as well as normal ones.

UAI · PMLR 216 · pp. 1219–1229 · Pittsburgh, PA, USA

Zhiwen Pan, Jiahao Li, Yiqiang Chen*, Salim Hariri, Jesus Pacheco, Xiaofan Song
